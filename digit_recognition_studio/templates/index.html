Model Architecture Details

This deep learning model is an Artificial Convolutional Neural Network (CNN) engineered specifically for structural pattern recognition on spatial matrix inputs.

1
Input Grid ($28 \times 28 \times 1$)

Grayscale drawing inputs converted to normalized numerical arrays.

2
Convolution Layer 1 (32 Filters, $3 \times 3$)

Extracts localized spatial features like lines, edges, and texture gradients.

3
Max Pooling (Size $2 \times 2$)

Reduces dimensional size, providing robust translational invariance.

4
Convolution Layer 2 (64 Filters, $3 \times 3$)

Combines low-level features to reconstruct geometric structures and shapes.

5
Dense Classifier + Dropout (50%)

Flattened feature outputs passed to fully connected layers for probability computation. Dropout prevents overfitting.
